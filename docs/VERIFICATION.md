## 已知限制及未验证项

- 尚未在真实 Linux Docker 引擎、真实域名、TLS 证书环境运行；Compose 配置静态检查和官方镜像标签核对通过，不能据此宣称上线成功。
- 当前 API/worker 按单实例、单渲染任务设计；没有服务器并发压测、浏览器多端兼容验收或多人协作。
- 只支持 MySQL CREATE TABLE 和 ALTER TABLE ADD FOREIGN KEY。ALTER 其他动作及非 DDL 语句明确报错，不静默跳过。图不显示检查约束、普通索引、默认值等非 Chen 结构信息。
- 再解析用表/字段原名称匹配。改变数据库原名称会被视为新结构；画布显示改名保留 ID。再解析会以 SQL 外键替换手工关系，确认框有说明，执行前保留恢复点。
- 排版保留完整结构，但密集关系、平行关系或很长名称可能需要手工调整；不保证任意图零交叉。
- 节点宽高按实体/属性/关系种类统一设置，整体倍率为 1–2 倍；未提供每个单独节点的自由缩放手柄。高度为最小值，长文字自动扩展。
