## 本轮修正

2026-10-26 页面介绍重新采用紧凑文字与帮助入口；工作区之后放置三步使用方法、SQL 规范入口和六项折叠常见问题。下方两张卡片与编辑器、预览使用相同的 42% / 剩余空间及 18 px 间距，四边对齐。电脑双栏（宽度至少 1000 px）采用首屏高度分配，移除原有 640 px 最小高度限制；较矮窗口隐藏重复的保存说明，SQL 和实体列表在框内滚动。窄屏延续上下排列，不将两框挤成不可用的小画布。新增八档电脑窗口的坐标验收，以及帮助键盘操作、错误提示、内部滚动和窗口缩放检查；没有改动业务模型、拖动逻辑或导出渲染。

按后续反馈，常见问题改成单项展开；普通图按钮与滚轮缩小最低 20%，复杂图按完整适应倍率作为下限，避免强制 20% 导致整图被裁切。低于 40% 时隐藏过密点阵，默认白底和用户背景设置保持有效。PNG/JPEG 清晰度明确为标清 1 倍、高清 2 倍和超清 3 倍，沿用现有渲染倍率，也应用于逐实体 ZIP。增加真实鼠标/键盘/滚轮、背景像素、PNG/JPEG 分辨率/样式与逐实体图片解码检查，全部功能完成后统一回归。

2026-10-26 增加指定实体显示与一致导出、SQL 格式说明、成功生成历史、属性注释/原名切换和确认后永久重置。美化改为完整属性群与独立菱形参与布局，保留主方向通道；按钮首次横向、第二次纵向，之后交替。增加默认布局按钮和说明。全页字体增大、SQL 工具按钮化、统一操作框高度和箭头居中，编辑器加宽至约 42%；新增三档桌面窗口检查。功能与 UI 合并完成后统一执行整套验收，状态以 VERIFICATION 为准。

2026-10-26 按用户最新要求停止 REA，恢复原工程正常开发；删除上轮源码备份、REA 工作副本和恢复验证副本（75,352,276 字节），删除自动建基线脚本，不再自动备份。移除 X6 框选插件、节点/整体选中框和拖动模式按钮，改为空白区域直接平移；保留 Shift 点选及快捷键，定位线改虚线。

拖动精度从 20 单位改为 1 单位，20 单位背景点阵独立保留；减小吸附容差，属性跟随实体的实际位置修正。纯位置更新不清空重建节点和边，松手、撤销、重做复用原 SVG。真实浏览器已先复现 10 次细小鼠标移动只得到 1 个位置的故障，再验证修复后得到 10 个位置；新增复杂画布拖动与操作回归。

补充实现关系基数独立拖动、位置保存/撤销与端点实时跟随（含自关联折线），增加 M 选项。双击基数可调整值、字体、8–72 号字号、粗细及颜色，支持取消、恢复全局样式；位置与样式在刷新、项目文件、复制及 SQL 匹配更新中保留。共享渲染已用于 PNG/JPEG/SVG/Draw.io/PDF，包含移动到节点范围之外的基数。实际下载、像素检查、PDF 内嵌字体及官方 Draw.io 编辑器的样式/位置/独立编辑验证已通过。

前轮样式与交互完善：分组样式草稿/应用/默认恢复、旧项目样式迁移、关联与基数显隐、主键下划线粗细、字体粗细、独立文字/线条颜色、文字背景、节点宽高与形状、自适应宽度、四向/边缘连接、属性排列与连接长度。新增全屏与 Esc 返回、窗口放大回退、实体与属性实时联动、Ctrl 固定半径拖动属性。PNG/JPEG 支持每个实体及全部属性单独生成并打包 ZIP，包含进度和取消。前轮的拖动模式开关已由本轮直接平移替代。

实测修复了全屏时 X6 宿主固定宽高导致右侧不能操作，以及吸附覆盖 Ctrl 圆周约束的问题。新增 10 项单元测试和 7 项真实浏览器测试；完整回归通过，未进入其他图种。服务器上线状态仍按下述未验收事项处理。

- X6 同步渲染避免清空并重建时残留重复视图。
- MySQL 解析器按具体方言导入，ELK 按需加载，减少初次脚本体积。
- 输入 SQL 和修改标题不触发整图重绘。

- 长文字按椭圆/菱形内部范围换行；自关联绘制两条独立连线。
- 修复本地代理改写 Host 导致浏览器 PDF 请求被误拒绝的问题。
- 修复 Windows 进程路径记录格式；停止时校验 PID、启动时间和程序路径，并处理本项目子进程。
